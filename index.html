1. Pengantar Function dalam SQL Oracle

Function adalah bagian dari SQL expression yang dipakai untuk mengolah data berupa teks, angka, tanggal, maupun hasil perhitungan lain. Berdasarkan jumlah baris yang diproses, function dibagi dua:

Single-Row FunctionMultiple-Row (Aggregate) Function
InputSatu barisSekelompok baris
OutputSatu nilai per barisSatu nilai per kelompok/seluruh tabel
ContohUPPER, LPAD, ROUND, ADD_MONTHSCOUNT, AVG, SUM, MAX, MIN
Dipakai diSELECT, WHERE, ORDER BYSELECT, HAVING, ORDER BY

Skema HR yang dipakai: tabel EMPLOYEES (employee_id, first_name, last_name, email, hire_date, job_id, salary, commission_pct, manager_id, department_id). Klik blok kode mana pun untuk mencobanya di Playground di bagian bawah.

2. Single-Row Function

Definisi: fungsi yang menerima satu baris sebagai input dan menghasilkan satu nilai output untuk setiap baris. Jika ada 10 karyawan, Oracle mengolahnya satu per satu, menghasilkan 10 output.

Analogi: barista di coffee shop. Pelanggan A minta cappuccino extra milk, B americano tanpa gula, C latte art. Barista memproses tiap pesanan satu per satu sesuai permintaannya — begitu juga tiap baris data diproses sesuai "resep" function-nya.

Kategori yang dipelajari:

  • Character: UPPER, LOWER, LPAD, RPAD, REPLACE
  • Number: ROUND, TRUNC, MOD
  • Date: SYSDATE, DATE ± NUMBER, ADD_MONTHS, MONTHS_BETWEEN

3. Multiple-Row (Aggregate) Function

Definisi: fungsi yang memproses banyak baris sekaligus lalu mengembalikan satu nilai ringkasan (untuk seluruh tabel atau tiap kelompok bila memakai GROUP BY).

Analogi: tiga teman ke café: kopi 25rb, latte 30rb, matcha 35rb. Saat bayar, Dika bilang "total 90 ribu, rata-rata 30 ribu per orang". Tak peduli siapa memesan apa — yang penting satu angka rangkuman.

Catatan penting: semua fungsi agregat mengabaikan NULL, kecuali COUNT(*).

4. Character-Manipulation Functions

UPPER & LOWER

Syntax: UPPER(teks), LOWER(teks). Mengubah huruf menjadi kapital / kecil. Berguna untuk menstandarkan penulisan, pencarian tanpa peduli besar-kecil huruf, dan laporan yang konsisten.

SELECT UPPER(first_name || ' ' || last_name) "NAMA UNTUK ID CARD"
FROM employees;

Hasil contoh: STEVEN KING. Operator || menggabungkan (concatenate) teks.

SELECT LOWER(first_name || '.' || last_name) || '@technova.com' "Email Perusahaan"
FROM employees;

Hasil contoh: steven.king@technova.com

LPAD & RPAD

Syntax: LPAD(teks, panjang, karakter_pengisi) — menambah karakter di sisi kiri sampai panjang total tercapai. RPAD menambah di sisi kanan. Jika teks lebih panjang dari panjang, teks dipotong.

SELECT last_name, salary, LPAD(salary,10,'*') FROM employees;

1000 → ******1000 (kiri)  |  RPAD: 1000 → 1000****** (kanan)

Kasus: laporan karyawan bergaji di bawah 4.000 USD dengan simbol mata uang rata kiri:

SELECT last_name, LPAD(salary,6,'$ ') "Gaji Dolar",
       LPAD(salary*15000,11,'Rp.') "Gaji Rupiah"
FROM employees WHERE salary < 4000;

REPLACE

Syntax: REPLACE(teks, yang_dicari, pengganti). Dipakai saat istilah/kode berubah, memperbaiki teks salah secara massal, atau mengubah tampilan tanpa mengubah isi tabel secara permanen.

SELECT job_id "Kode Lama", REPLACE(job_id,'CLERK','STAFF') "Kode Baru"
FROM employees;

Hasil contoh: SH_CLERK → SH_STAFF, ST_CLERK → ST_STAFF.

SELECT last_name "Nama Karyawan", salary "Gaji per bulan",
       salary/30 "Gaji Perhari", ROUND(salary/30,2) "Gaji Perhari (dibulatkan)"
FROM employees;
SELECT last_name, salary, salary/30, ROUND(salary/30,2), TRUNC(salary/30,2)
FROM employees;
SELECT last_name, salary, MOD(salary,3) FROM employees;

6. Date Functions

Mengelola dan menghitung data bertipe DATE: menampilkan tanggal sekarang, menghitung masa kerja, menentukan jatuh tempo, atau memprediksi evaluasi/kenaikan gaji.

SYSDATE

Tanggal & waktu sistem database saat ini. DUAL adalah tabel dummy satu baris.

SELECT SYSDATE FROM dual;
SELECT first_name || ' ' || last_name "Nama Karyawan", SYSDATE "Tanggal Laporan"
FROM employees;

DATE + NUMBER

Menambah/mengurangi hari. Selisih dua tanggal (tgl1 - tgl2) menghasilkan jumlah hari.

SELECT first_name || ' ' || last_name "Nama", hire_date "Tanggal Masuk",
       hire_date + 90 "Tanggal Kontrak Berakhir"
FROM employees;

Contoh: 17-JUN-87 + 90 = 15-SEP-87

ADD_MONTHS

Syntax: ADD_MONTHS(tanggal, n) — tambah/kurangi n bulan. Contoh: ADD_MONTHS('17-JUN-87',6) = 17-DEC-87. Evaluasi 6 bulanan:

SELECT first_name || ' ' || last_name "Nama", hire_date "Tanggal Masuk",
       ADD_MONTHS(hire_date, 6) "Tanggal Evaluasi Berikutnya"
FROM employees;

10 tahun = 120 bulan: ADD_MONTHS(hire_date,120).

MONTHS_BETWEEN

Syntax: MONTHS_BETWEEN(tgl_akhir, tgl_awal) — selisih bulan berupa angka desimal; biasanya dibungkus ROUND.

SELECT first_name || ' ' || last_name "Nama", hire_date "Tanggal Masuk",
       SYSDATE "Hari Ini",
       ROUND(MONTHS_BETWEEN(SYSDATE, hire_date), 0) "Lama Kerja (Bulan)"
FROM employees;

Literal tanggal ditulis dengan format 'DD-MON-YY', mis. '14-JAN-99'.

7. Aggregate Functions

FunctionFungsiCatatan
COUNTBanyaknya dataCOUNT(*) menghitung semua baris; COUNT(kolom) hanya yang tidak NULL
AVGRata-rata (mirip AVERAGE di Excel)NULL diabaikan
SUMJumlah totalHanya untuk angka
MAX / MINNilai tertinggi / terendahBerlaku juga untuk teks & tanggal
SELECT COUNT(*) FROM employees;
SELECT COUNT(department_id) FROM employees;
SELECT COUNT(*) FROM employees WHERE salary > 5000;
SELECT AVG(salary) "Rata-rata Gaji" FROM employees;
SELECT SUM(salary), MIN(salary), MAX(salary)
FROM employees WHERE department_id = 20;

8. Pengelompokan: GROUP BY, HAVING, ORDER BY

GROUP BY membagi baris menjadi kelompok; fungsi agregat dihitung per kelompok. HAVING menyaring kelompok (bukan baris). ORDER BY mengurutkan hasil (DESC = menurun).

SELECT department_id, AVG(salary) "rata-rata gaji"
FROM employees GROUP BY department_id;
SELECT department_id, MAX(salary)
FROM employees
GROUP BY department_id
HAVING MAX(salary) > 6000
ORDER BY MAX(salary) DESC;
WHEREHAVING
Menyaring baris sebelum pengelompokanMenyaring kelompok setelah pengelompokan
Tidak boleh memuat fungsi agregat (ORA-00934)Boleh memuat fungsi agregat

Urutan eksekusi logis: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY.

Aturan emas: setiap kolom di SELECT yang bukan fungsi agregat wajib ada di GROUP BY, jika tidak muncul error ORA-00979: not a GROUP BY expression.

9. Ringkasan & Kesalahan Umum

  • Single-row → output sebanyak baris input; multiple-row → satu nilai per kelompok.
  • Teks harus diapit tanda kutip tunggal '...'; alias dengan kutip ganda "...".
  • LPAD/RPAD memotong teks bila lebih panjang dari panjang yang diminta.
  • ROUND membulatkan, TRUNC memotong — hasil bisa berbeda di digit terakhir.
  • COUNT(kolom) ≠ COUNT(*) bila kolom mengandung NULL.
  • Jangan memakai agregat di WHERE; pakai HAVING.
